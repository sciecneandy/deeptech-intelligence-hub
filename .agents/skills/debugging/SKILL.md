# Debugging

1. Establish expected and actual behavior and inspect relevant code, errors, and project instructions. Reproduce the issue when practical; record constraints if reproduction is unavailable.
2. Trace the failure to its cause using evidence. Test plausible hypotheses with focused, safe checks; distinguish confirmed facts from assumptions.
3. Make a focused fix consistent with the project. Add a regression test when it meaningfully protects the behavior and is proportionate to the change.
4. Run relevant checks and, where possible, repeat the original reproduction. Explain the cause, fix, validation, and any unresolved uncertainty.
